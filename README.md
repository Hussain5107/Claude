# Project Index

This repository used to hold many unrelated projects as branches, which made
them hard to find and caused them to interfere with each other (builds from one
project firing on another's branches, files bleeding between them).

Every project now lives in its own repository. This repo is kept only as a
scratch space for new Claude Code sessions and as the index below.

## Starting a new project

Create a dedicated repository for it **first**, then point the Claude Code
session at that repository. Don't add it as a branch here — that is what caused
the tangle this index replaces.
